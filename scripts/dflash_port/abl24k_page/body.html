Methods

What was compared

Every arm adapts the same frozen drafter: rank-r LoRA on q, k, v and o of all 5 layers, coefficient α/r = 2. They differ only in where the LoRA comes from (one learned LoRA, or a network that makes one per prompt), its rank, and the loss.

M1Static LoRA vs generator, and how head sharing shrinks the generator

The head biases are a static LoRA of their own, so every generator is "a static LoRA + a part that depends on the prompt". Sharing heads keeps the code width and rank and cuts the generator 5×; rank 64 with shared heads (≈ 0.45B) is still under the 500M target, while rank 64 with per-module heads would be 2.2B.

Losses

  • KL: KL(target ‖ drafter) per slot, weighted by D-PACE. The gate is built as exp(−KL), which is not a probability of acceptance (the reference loss).
  • CE: cross-entropy on the target's argmax, D-PACE α 0.5. Here the gate is the drafter's probability of the target token, as upstream intends.
  • KL + label gate α 0.1 (new): KL per slot, gated on the drafter's probability of the target's argmax, with a sharper gate. At α → 0 the label-gated CE is exactly the gradient of expected accepted length (unit-tested).

Shared protocol

  • 24,000 training rows (6K each of math, code, stem, chat), 2 epochs = 2,667 updates, 18 rows per update, AdamW 1e-4, seed 42.
  • Validation and test: 500 rows each (200 math + 100 code / stem / chat); OOD v3: 240 rows (HumanEval, math reasoning, summarization).
  • τ = accepted draft tokens per block + 1, offline, greedy, teacher-forced; category mean. Differences are paired, 95% bootstrap over rows, stratified by category.

Limits

What these numbers do not show

  • One seed per arm. Earlier records put seed drift near the size of the smaller differences here.
  • Offline, greedy, teacher-forced τ on stored responses; no vLLM serving measurement.
  • 2 epochs; the 3-epoch MIX24K runs were still rising at the end, so longer training may change the ordering.
  • The base drafter was likely trained on prompts from the same Nemotron Post-Training V2 source, which limits the headroom of every arm.
  • Loss values are not comparable across arms (D-PACE weights depend on each arm's own gate); compare τ.
