## What is tested

Which training loss suits the DFlash generator?

## Methodology

Generator losses CE + D-PACE ★ (= M0), CE + fixed exponential position decay γ = 7 (DFlash paper value for block 16), KL to the verifier distribution (`kl_div`, D-PACE weights), and `lk_hybrid` (the EAGLE-3 generator loss, D-PACE weights). EAGLE-3 GEN-006 compared LK / CE / KL. Each arm is the M0 recipe with only `training.block_drafter.loss_fn` / `per_position_loss_weight` changed (`training_recipes/loss_*.yaml`): attention targets, rank 32, 4K pool, 1,500 updates, seed 42, 200 fixed validation rows. Generators only; the M0 static LoRA (CE + D-PACE) is the reference.

## Measurements

Acceptance per category; the shape of the per-position accuracy curve (`position_k_acc`, k = 1…15, from the validation pass; each position is judged on its own, not conditioned on earlier positions).

Findings (4K pool, one seed):

- **KL and lk_hybrid overfit more slowly than CE.** Same peak as M0 (≈ 0.529 at update 250) but they end at 0.5247 (= base 0.5246) instead of 0.5220. Both remain below the M0 static LoRA (0.5304).
- **CE + exp-decay γ7 is the worst arm**: lower peak (0.5262) and the lowest final score (0.5165, below base). Its acceptance drops at every position, including p1 (0.877 vs base 0.886), so it is not a trade of early for late positions.
- **Per-position curves have the same shape for all arms**; the differences are small uniform shifts (≤ 0.01 per position). No loss changes where in the block the drafter gains or loses. The M0 static LoRA is highest at every position from p2 on.
- **At s = 1 KL and lk_hybrid reach 0.5293–0.5296**, the best generator numbers so far, still below static.
- **The correct donor is still not better than a fixed ΔW at s = 2** (KL −0.0024, lk_hybrid −0.0010); for lk_hybrid it equals cross-category.
- **γ7 produces the most row-specific but least category-structured ΔW** (dyn_ratio 0.33, η² 0.59, centroid accuracy 0.915), and this does not translate into acceptance.

Open: whether the KL / lk_hybrid advantage (slower overfitting) persists on the 24K pool, where M0's CE may not overfit; a candidate for the Tier 5 configuration choice.
