## What is tested

Can heads be shared across layers (far fewer generator parameters) without losing strength?

## Methodology

`adapter.head_sharing`: per-module ★ (= M0, as EAGLE-3) has one A/B head per adapted module key, i.e. per (module, layer). per-type has one head per module type (q / k / v / o) shared by the five layers, which are told apart by a learned `layer_embedding` input (`src/speculators/generator/model.py`). Everything else is as in M0 (attention targets, rank 32, 4K pool, 1,500 updates, seed 42, 200 fixed validation rows). Generator only.

## Measurements

Acceptance per category and per position; generator parameters; offline M4 / M7 / D13 / D14.

Findings (4K pool, one seed):

- **Sharing heads across layers costs nothing measurable at 1/5 of the parameters** (0.45B vs 2.20B). Peak 0.5288 vs 0.5289, final 0.5227 vs 0.5220, best offline coefficient 0.5294 vs 0.5289. Per-position curves overlap within 0.005.
- **The generated ΔW have the same structure**: dyn_ratio 0.270 vs 0.268, cross-row cosine 0.667 for both, centroid accuracy 0.965 for both.
- **The overfitting shape is unchanged** (peak at 250, then a decline). The 5× smaller per-type generator still overfits the 4K pool. Total parameter count alone does not set the decline; compare the D2 single-layer generators, also 0.45B, which ended at 0.5233–0.5239.
- **Correct donor < fixed ΔW at s = 2** again (−0.0029).
- Per-call latency does not change (4.3 vs 4.5 ms; the heads still produce every layer's factors).
