## What is tested

How many conditioning rows does the generator need?

## Methodology

Generators trained and validated with K = 2, 4, 8 rows per generated LoRA (M0: K = 1), about 18 rows per update (9 / 4 / 2 groups). Everything else as M0.

A K-grouped validation number is compared only with a number of the same grouping, because the validation anchors are drawn over each packed group (P2 finding). Two paired comparisons:
1. at each arm's own K: the M6 generator vs the M0 static LoRA evaluated with the same grouping;
2. at K = 1 (one row per LoRA, as served): each M6 generator vs the M0 generator and static. One row is outside a K-trained generator's trained K.
