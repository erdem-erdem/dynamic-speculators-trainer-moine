## Methodology

Donors: correct ★ · fixed (one LoRA for every row, from the first row by primary id of the unseen `chat-00002` validation split) · cross_category (a random unseen `*-00002` row of the next category, cyclic). same_category only behind `allow_same_category`. Donor rows are never trained on or evaluated; donor sets have the cohort's size (1 row: one LoRA per row).

## Measurements
