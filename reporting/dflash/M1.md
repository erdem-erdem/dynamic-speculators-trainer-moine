## What is tested

Which modules should the generated LoRA adapt?

## Methodology

Target sets: attention q/k/v/o ★ (this is M0), MLP (`gate/up/down_proj`), and all (attention + MLP). Each set has a matched static LoRA (EAGLE-3 GEN-009/010, `structure_ablations_v1/modules`). Everything else is as in M0: rank 32, α = 64 (scale 2), 4K pool, 1,500 updates, seed 42, one LoRA per row, the 200 fixed validation rows every 250 updates. Offline evaluation of the final checkpoint covers reproduction, M4 coefficients, M7 donors, the K=4 view, D13 and D14. Test and OOD splits are run for M0 only (`tier1_final`).

## Measurements

Acceptance (score = `full_acc`, τ = `eal`) per category; generator vs its own static, per set; D13 similarity; D14 cost.

Findings (measurements on the 4K pool, one seed):

- **The static LoRA beats the generator for every target set.** The gap is 0.008 to 0.012 score at the training scale. The statics are almost identical across sets (0.5294–0.5304). Adapting more modules does not help a static LoRA here.
- **Every generator follows M0's overfitting shape.** Each peaks at update 250 (0.5277–0.5289), above base and close to the statics, then falls below base by update 1500. The larger generators (MLP 4.05B, all 6.23B) end slightly lower than attention (2.20B), so more capacity is not rescuing them.
- **At s = 0.5–1 every generator recovers to about 0.528–0.529**, which is still below its static. The per-row oracle gain is +0.04–0.10 τ, the same order as M0's.
- **The correct donor is the worst donor at s = 2 for all three sets.** A fixed or cross-category ΔW scores higher than the row's own. Whatever per-row information the generator learned does not help acceptance at this scale and pool size (as for M0).
- **Adding modules raises cost.** Attention → all doubles latency per call (4.5 → 9.0 ms) and quintuples merge time (0.68 → 3.25 ms). "All" also gives the least row-specific ΔW (dyn_ratio 0.18, cross-row cosine 0.78).

Open: whether the ordering holds on the 24K pool, where the generator should overfit less (Tier 5).
