## What is tested

Does adapting all 5 layers matter, compared with EAGLE-3's single layer?

## Methodology

Adapters on all 5 draft layers ★ (= M0), on layer 0 only, or on the last layer (4) only (`adapter.layers`). Each layer set has a matched static LoRA. Attention targets, rank 32; everything else as in M0 (4K pool, 1,500 updates, seed 42, 200 fixed validation rows).

## Measurements

Acceptance per category and per position; offline M4 / M7 / D13 / D14.

Findings (4K pool, one seed):

- **For the static LoRA, all five layers is best**: 0.5304 vs 0.5269 (layer 0) and 0.5258 (layer 4). The all-layers static is also highest at every position from p2 on.
- **For the generator, a single layer ends higher than all five** (0.5233 layer 0, 0.5239 layer 4 vs 0.5220) because it overfits less. A single-layer generator is 0.45B parameters vs 2.20B. The layer-0 generator peaks late (0.5260 at update 1000) instead of at 250. Its peak is lower than the all-layer generator's (0.5289), and the best offline coefficient brings all-layers and layer-0 to the same 0.5289. Layer 4 tops out at 0.5271.
- **Each single-layer generator is still below its matched static** at the final checkpoint: layer 0 by −0.0036, layer 4 by −0.0019.
- **The correct donor is again below a fixed ΔW at s = 2** for both single-layer generators. The layer-0 gap is the largest seen so far (−0.0035).
- **Cost:** one adapted layer cuts generator latency per call by 2–4× (1.1–2.4 ms vs 4.5 ms) and merge time by 5× (0.14 vs 0.68 ms).
