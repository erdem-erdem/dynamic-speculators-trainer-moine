## What is tested

How does rank affect generator strength and end-to-end cost?

## Methodology

Generator rank 8 · 16 · 32 ★ (= M0) · 64 on the attention targets (EAGLE-3 GEN-005), with α = 2r so the training scale α/r = 2 stays fixed (`training_recipes/rank*.yaml`). Everything else is as in M0 (4K pool, 1,500 updates, seed 42, one LoRA per row, 200 fixed validation rows). No static arms: the M0 static (rank 32) is the reference. Offline evaluation of each final checkpoint covers reproduction, M4, M7, K=4, D13 and D14.

## Measurements

Acceptance per category; dyn_ratio, effective rank, category accuracy; generator latency, parameters, merge time.

Findings (4K pool, one seed):

- **Final score falls as rank grows** (0.5239 → 0.5225 → 0.5220 → 0.5198). Peaks at update 250 are all about 0.528–0.529, so rank changes how far the generator overfits, not how good it gets. Higher rank means more generator parameters (0.56B → 4.38B) on the same 4K rows. Every rank ends below the M0 static LoRA. Only r8 ends at or just below base, and the r8–r32 differences are within about 0.002.
- **At s = 0.5–1 every rank recovers to 0.529**, about the M0 generator's peak. The per-row oracle gain stays +0.04–0.13 τ.
- **The correct donor is still worse than a fixed ΔW at s = 2 for every rank.** The gap is smallest at r64 (−0.0017) and largest at r8 (−0.0028).
- **Generated ΔW become less row-specific as rank grows:** dyn_ratio 0.38 → 0.22 and cross-row cosine 0.53 → 0.73. Category separability does not change: η² ≈ 0.74, centroid accuracy ≈ 0.96–0.97.
- **D14 latency per call is not monotonic in rank** (7.3 ms at r8, 4.5–4.8 ms at r32/r64). It was measured on a shared box with the other lane training on the second GPU, so the timings are noisy and do not support a latency ranking between ranks. Parameter counts and factor sizes are exact. Merge time does not depend on rank (≈ 0.7 ms).

Open: the rank ordering on the 24K pool (Tier 5), where overfitting is expected to be smaller; a quiet-box D14 re-measurement if latency matters for the choice.
